# KINZOKU

Official one-page site for **KINZOKU**, the steel samurai dog of Solana.

Live page: https://postwawpl-ship-it.github.io/kinzoku/

## After launch

Edit the config block at the **top of `index.html`** (in the first `<script>` tag):

- `CONTRACT_ADDRESS` — the Solana / Pump.fun contract address (the Copy button will start copying it)
- `PUMPFUN_URL` — official Pump.fun coin page (replaces the `#` placeholder on Buy buttons)
- `TWITTER_URL` — official X / Twitter profile

Commit and push to `main`. GitHub Pages will refresh in a minute or two.

Do not paste a contract address from anywhere except the wallet / Pump.fun page used at creation.
